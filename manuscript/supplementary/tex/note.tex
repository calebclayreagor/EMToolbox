{\bfseries MesenContext: Run summaries\par}\vspace{2pt}
Analysis summaries for every run in the run ledger (Supplementary Methods), ordered by category, disease, dataset, and run. Each page reports the gate outcomes, manifold geometry, and module
signatures produced by the agent for that run. These summaries were harmonized after the full
analysis, and their results are consistent with those generated during each run. Two pruned runs are absent: Chen2020 (run 6 of 7)
and Ji2020 (run 9 of 10).\par\vspace{12pt}
